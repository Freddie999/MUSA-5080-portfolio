# Philadelphia housing values

Team report by Vincent Bio Bediako, Frederick Abalo, and Emmanuel Sampson.

The HTML preserves the existing executed report and results; the title and local filesystem paths were adjusted for publication, an unavailable PDF link was removed, and descriptive image alt text was added. The source uses relative input paths.

To rerun, obtain the course-provided RegressionData.csv and RegressionData.shp directory and place them under data/housing-values/ in the repository root. The supplied dataset is not redistributed here. Run quarto render reports/philadelphia-housing-values-source.qmd --execute-dir . explicitly after installing the R dependencies listed in the source. The website build copies the existing report without rerunning it.
